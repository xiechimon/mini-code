# Spec: Markdown 正文渲染

Status: resolved

## Problem Statement

助手回复以裸 Markdown 倾倒到终端：表格的管道符、`**` 星号、`##` 井号原样上屏，用户在 REPL 里看到的回复难以扫读——真实痛点样例（一轮 Maven 版本问答）里就包含一张管道表格、多级标题与粗体，全部以原始字符呈现。

## Solution

助手消息正文经 Markdown→终端文本渲染管线呈现：commonmark 解析 + 自研主题渲染器（标题粗体青色、行内代码绿色、代码块边框盒、列表青色圆点、引用灰斜、链接下划线暗 URL、表格自适应对齐），按终端宽度做 ANSI 感知折行；`NO_COLOR`/非 tty/`TERM=dumb` 下降级为保留结构（缩进/边框/前缀/表格对齐）的纯文本。工具结果与轮首行维持既有摘要渲染不变。

## User Stories

1. 作为终端用户，我希望助手回复中的表格渲染为列宽自适应的对齐文本表格，以便一眼比较各项数据
2. 作为终端用户，我希望表格表头加粗、分隔线暗灰，以便区分表头与数据行
3. 作为终端用户，我希望标题渲染为粗体青色，以便扫读回复的结构骨架
4. 作为终端用户，我希望粗体/斜体/删除线转为对应的 ANSI 样式，以便强调语义不丢失
5. 作为终端用户，我希望行内代码渲染为绿色，以便一眼认出命令与标识符
6. 作为终端用户，我希望围栏代码块渲染为边框盒（上下边线+左竖线、内容暗灰），以便与正文清晰区隔
7. 作为终端用户，我希望代码块保持原始行不折行，以便复制时内容完整
8. 作为终端用户，我希望列表渲染为青色圆点并保持层级缩进，以便嵌套结构可读
9. 作为终端用户，我希望引用块渲染为 `|` 前缀加暗灰斜体，以便区分转述与正文
10. 作为终端用户，我希望链接渲染为文本下划线、URL 暗灰，以便知道可点击目标而不被长 URL 干扰
11. 作为终端用户，我希望段落按终端宽度自动折行（ANSI 码不计入宽度），以便窄窗口不横滚
12. 作为终端用户，我希望在窄终端下表格列宽被压缩仍保持对齐，以便小窗口可用
13. 作为管道/脚本使用者，我希望 `NO_COLOR` 下渲染结果保留全部结构（缩进/边框/前缀/表格对齐）但无任何 ANSI 码，以便日志与 grep 干净
14. 作为管道/脚本使用者，我希望非 tty 与 `TERM=dumb` 同样走结构保留降级，以便在最小环境中正常阅读
15. 作为管道/脚本使用者，我希望管道模式下折行宽度固定为 80 列，以便输出宽度可预期
16. 作为终端用户，我希望工具结果与轮首提示维持既有摘要渲染不变，以便两类输出风格一致且可区分
17. 作为维护者，我希望正文渲染是纯函数（输入 markdown/样式/宽度，输出文本），以便不启终端即可单测
18. 作为维护者，我希望解析与主题渲染分离，以便未来替换解析器或调整主题互不影响
19. 作为维护者，我希望新增依赖收敛在 commonmark 官方 artifact 家族（零传递依赖），以便依赖面最小化
20. 作为维护者，我希望终端宽度由调用方注入（交互模式取终端宽度、管道模式 80），以便渲染器保持确定性
21. 作为维护者，我希望 HTML 块按纯文本原样输出而不解析执行，以便安全且行为可预期
22. 作为维护者，我希望依赖决策有 ADR 记录，以便后人理解零依赖项目中为何引入解析器
23. 作为维护者，我希望每类 Markdown 结构都有去色/有色两态的输出字符串断言，以便防止回归

## Implementation Decisions

- 在 cli 渲染层新增正文渲染器：纯函数，输入 Markdown 文本、样式开关、可用宽度，输出终端文本；遵循既有纯函数渲染缝纪律（不读环境、不碰时钟）
- 事件渲染接线：助手消息的事件分支在输出正文前经正文渲染器；工具结果、轮首、横幅、轮末统计的渲染路径不变
- 解析器：commonmark 核心 + ext-gfm-tables 官方扩展（决策记录见 ADR-0001）；HTML 块按纯文本原样输出
- 样式映射：标题粗体青色；粗体/斜体/删除线对应 ANSI 粗/斜/删除；行内代码绿色；代码块边框盒、内容暗灰；列表圆点青色、层级缩进；引用 `|` 前缀暗灰斜体；链接文本下划线、URL 暗灰；表格表头粗体、分隔线暗灰
- 表格：列宽按内容自适应，可用宽度不足时按比例压缩列宽，保持对齐
- 折行：段落、列表项、引用按可用宽度折行，ANSI 码不计入宽度；代码块与表格行不折行（表格靠列宽压缩适配）
- 宽度来源：交互模式注入终端实际宽度，管道模式固定 80；渲染器自身不探测终端
- 降级：样式关闭时同一套结构规则（缩进/边框线/前缀/表格对齐/折行）输出纯文本，无任何 ANSI 码
- 术语遵循 CONTEXT.md：正文渲染（事件渲染的子层）、纯函数渲染缝、事件渲染

## Testing Decisions

- 单缝原则：全部结构与降级断言收敛在正文渲染器纯函数缝上——给定 markdown/样式/宽度，断言输出字符串（有色与去色两态都覆盖）
- 只测外部行为：断言输出文本的内容与结构（对齐、前缀、边框、折行位置），不断言解析器内部节点
- 事件渲染接线复用现有渲染器测试缝，补一条「助手文本经正文渲染」的断言
- 先例：EventRendererTest（渲染纯函数字符串断言）、StyleTest（降级开关）、MainReplTest（输入编辑器缝）
- 边界用例：可用宽度 0/极窄、超长不可断词、表格列宽压缩、嵌套列表、连续混合结构、空文本、代码块含特殊字符

## Out of Scope

- 代码块语法高亮（highlight.js 等价物，Java 侧无轻量方案）
- LaTeX/数学公式渲染
- 图片与 OSC8 终端超链接
- 任务列表（`- [x]`）复选框渲染
- 流式增量渲染（等待反馈面，归 MVP3）
- 工具结果的 Markdown 化
- HTML 的解析渲染（HTML 一律纯文本输出）
