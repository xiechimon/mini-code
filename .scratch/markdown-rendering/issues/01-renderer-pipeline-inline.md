# 01: 正文渲染管线贯通

**What to build:** 助手回复正文从裸 Markdown 变为渲染文本——引入 commonmark 解析（落地 ADR-0001，本项目首个运行时依赖，仅官方 artifact 家族、零传递依赖），正文渲染器纯函数（输入 markdown/样式/宽度，输出文本）接入事件渲染的助手文本分支。本票交付：段落、标题（粗体青）、粗体/斜体/删除线、行内代码（绿）、链接（文本下划线+暗灰 URL）的样式渲染；ANSI 感知折行（ANSI 码不计宽）；PLAIN 降级（结构保留、无 ANSI）；宽度由调用方注入（交互取终端宽度、管道固定 80）。验收演示：REPL 里让模型回一段带标题与粗体的回复，屏幕上即是渲染后的效果。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] commonmark + ext-gfm-tables 依赖引入，零传递依赖（ADR-0001 落地）
- [x] 正文渲染器为纯函数：不读环境、不碰时钟（样式与宽度均注入）
- [x] 段落/标题/粗体/斜体/删除线/行内代码/链接各有色与去色两态的输出字符串断言
- [x] ANSI 感知折行：段落按注入宽度折行、ANSI 码不计宽、超长不可断词有处理
- [x] PLAIN 降级：同一结构规则输出纯文本
- [x] 事件渲染接线断言：助手文本经正文渲染器；工具结果/轮首/横幅/统计路径不回归
- [x] 宽度注入：REPL 用终端宽度、管道模式 80
- [x] mvn test 全绿，pty 冒烟一条带标题粗体的真实回复
